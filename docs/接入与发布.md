# Agent 接入、远程空间选择与产品站点

更新：2026-10-23。保持 macOS ARM64 第一阶段范围，未接模型，未增加 Windows/Linux 原生实现。

## Ego 对照与当前能力

参考官方仓库 [ego-lite](https://github.com/citrolabs/ego-lite)、版本配套 [Skill](https://github.com/citrolabs/ego-lite/blob/main/package/ego-browser/skill-body/SKILL.md)、[插件](https://github.com/citrolabs/ego-lite/tree/main/plugins/ego) 与本机 Ego 0.6.0.16 / guide 2.1.0。其核心是 TaskSpace + Page SDK，插件负责把同一份 Skill 接入 Harness，不是一个可以直接复制的 MCP 服务。

采用的交互与工程方式：每个任务延续同一个空间；页标签与内部身份稳定；先观察、按引用操作、验证结果；明确接管和交还；插件共用 Skill；操作文档随适配器发布。我们的显示编号可以回收，原生内部 ID 和授权不可重定向。

| 能力 | Agentic Browser 当前实现 | 验证 |
|---|---|---|
| 空间隔离、主空间仅人操作 | 单空间凭证、租约与代次；页面协议白名单 | 已有主空间 403；本轮全局 Browser/Target、外部 session、释放后的租约被拒绝 |
| 语义观察、表单和框架 | 跨域 AX、引用、选择器、open shadow、select/contenteditable | SDK 与真实 stdio MCP 通过；1000 节点上限 |
| 页面交互 | 有界等待/JS、键鼠、快捷键、弹窗、动态上传、下载、fetch | 本地实际页面操作和返回结果通过 |
| 标签与截图 | 空间内标签、popup、原尺寸/整页 PNG；旧预览和 VNC 保留 | SDK popup、下载内容和截图；MCP 图片通过 |
| Harness 接入 | 33 MCP 工具、TaskSpace/Page SDK、CLI、统一 Skill 0.4.0、接入包 0.2.1 | Codex 0.163.0、Claude Code 2.1.251 用户级插件安装、发现、实际操作和交还通过 |
| Ego 参照 | 独立空白 Profile 的官方 SDK 运行 | 同一 fixture 的中文表单、跨域 iframe、select/contenteditable、快照与可信点击；公开网站检测对照 |
| API 等价边界 | 浏览器全局 CDP/存储、自动空间创建/关闭不开放；没有 viewport/subtree 快照、networkidle、worker 操作 | 保持用户限定范围；不能声称全部 Ego API 一比一等价 |

Codex 与 Claude Code 已分别完成用户级 Plugin 安装、Skill 发现和 33 个 MCP 工具连接；通过各自实际运行时完成中文填写、点击、人机交还、恢复和释放。交还期间的输入被拒绝，Computer Use 操作原生“交还给 Agent”按钮。此次未调用模型推理，不将运行时验收表述为模型自主任务效果验证。其他 Harness 尚未实装；其配置格式不能假设通用。真实工具契约为 `tools/list`，说明为 `agentic-browser://guide`。

两个插件默认分别读取 `~/.config/agentic-browser/codex.json` 和 `~/.config/agentic-browser/claude.json`，绑定各自明确授权的非主空间，避免共用默认文件导致争用。连接文件留在本机，权限 0600；浏览器重启或空间删除后需重新明确绑定。当前会话的插件发现可能需要新会话或重启 Harness。

详细能力、实际验证和 CDP 结论见 [Ego 能力对齐](Ego能力对齐.md)。

安装步骤见 [INSTALL](../integrations/INSTALL.md)。`npm run integration:pack` 输出私有 `.runtime/dist/*.tgz` 与 SHA-256；包内没有浏览器安装包、用户 Profile 或凭据。`scripts/bind-space.mjs` 只绑定明确选择的一个非主空间，不覆盖已有文件。源码插件的符号链接用于维护，安装套件会物化相关文件。

## noVNC 多空间

所有非主空间均获得独立 VNC capability。连接页按当前活动序号展示真实页面缩略图；主空间不进入列表。新增空间在重新打开选择器时读取，关闭后移除。

每个桥接服务保留单个远程客户端、单个选中空间。先断开，再选空间，再连接；切换清空旧帧和旧控制状态，首张 RFB 图像准备好之后才建立连接，避免短暂看到上一个空间。连接只观看，接管和交还显式进行，颜色仍为绿/红。列表与切换接口要求临时观看凭证，切换还要求同源请求。

Computer Use 已检查空间 1/2 缩略图、空间 1 观看→接管→交还→断开、切换空间 2 实际观看，且主空间没有出现在选择器。只补本次修改相关验收；既有手机/锁屏测试未重复。

## 网站与 CI/CD

站点源码 `website/`，地址 [charlesxu.github.io/AgenticBrowser](https://charlesxu.github.io/AgenticBrowser/)。纯静态 HTML/CSS/JS，系统字体，11KB Portal 图标，CSS 插图，中英文、深浅模式、窄屏适配；无追踪、外部字体或视频。首屏源码及图片约 32KB（压缩前）。

浏览器能提供可信平台信息时预选系统和架构，否则保留手动选择；不根据 Apple Silicon 浏览器中 Intel 字样猜架构。只有 `releases.json` 中实际存在、官方 GitHub URL 的资产才显示下载按钮。网站不会把私有 Release 链接误当公开下载。

`npm run site:releases` 匿名查询官方分发仓库最新稳定 Release。默认私有源码库，因此当前清单为空；未来通过 Actions 变量 `RELEASE_REPOSITORY` 指向经批准的公开分发仓库，无须公开源码。安装包命名：`Agentic-Browser-0.1.0-macos-arm64.dmg`（OS：macos/windows/linux；架构：arm64/x64），接入包 `agentic-browser-integration-0.2.1.tgz`。只录入已上传、有 GitHub SHA-256 digest 的资产。模型、签名公证与浏览器自动升级下载没有在本轮接入。

- `Project CI`：main push / PR / 手动触发；Node 24、语法、语言键/占位符、清单/本地链接、首屏体积和补丁语法检查；生成接入套件的私有 artifact。它不是 Chromium 编译验收。
- `Product website`：网站代码 push、Release 发布、每天或手动触发；刷新公开下载清单，仅上传 `website/`，部署 GitHub Pages。源码仓库保持 Private。
- Chromium 原生构建继续用既有本机脚本，不能在通用 GitHub hosted runner 的短检查中声称已完成全平台编译。

官方依据：[GitHub Pages 工作流](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)、[Release API](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)、[Claude 插件格式](https://code.claude.com/docs/en/plugins-reference)。部署与 CI 的实际结果在实施记录中追加，文件存在不代表已上线。
